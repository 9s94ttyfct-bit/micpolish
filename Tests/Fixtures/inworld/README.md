# Inworld Voice Isolator v1 (offline) parity fixtures

Upstream, pinned:

- Code: `inworld-ai/voice-isolator` (https://github.com/inworld-ai/voice-isolator),
  commit `c73b3fab81a870410cbac50d2f05f25edc4d10aa` (2026-11-18, package
  `inworld-voice-isolation` 1.0.0), Apache-2.0. The port follows
  `src/inworld/voice_isolation/model.py` (`VoiceIsolatorNetwork.forward` and
  `.enhance`), `isolator.py` (offline `VoiceIsolator.isolate`) and `scan.py`.
- Weights: `inworld/voice-isolator` revision `9b0285b3fe8403aa8e2f1dbb2165a80a4294c970`,
  `denoiser.safetensors` (registry name `voice-isolator-v1`), 256,260,128 bytes,
  SHA-256 `647335a6aeb4dc706b895532c209d51e0e84a4849d17b339f00d4392a050ae53`,
  Apache-2.0. The Swift port loads this file as is; its architecture comes from
  the file's `config` metadata (8 s windows, 2 s linear crossfade, n_fft 2048,
  hop 480, 46 bands, width 512, 7 blocks).

Files:

- `noisy_4s.wav`: 191,000 samples (3.98 s, not a multiple of the 480-sample hop),
  48 kHz mono PCM16. The first 191,000 samples of `../lava/speech_8k_band.wav`
  (speech with no content above 8 kHz, derived from NVIDIA materials under
  OpenMDW-1.1, see `../reuse/README.md`) plus noise generated by
  `inworld_reference.py --make-fixtures` (seeded hiss, 60 Hz hum with harmonics,
  six clicks) at 6 dB SNR. Shorter than one window: a single pass.
- `stream_16s.wav`: 760,123 samples (15.84 s), 48 kHz mono PCM16: upstream
  `demo/examples/sample_14.wav` followed by `sample_15.wav` (at the pinned commit),
  copied without resampling and cut. Three 8 s windows at a 6 s stride; the
  length is not a multiple of the hop and the last window sits at the clip's end,
  off the stride. Both examples are LibriSpeech utterances (2277-149896-0032 and
  2035-147960-0000; LibriSpeech © 2014 Vassil Panayotov, CC BY 4.0, per upstream
  `demo/examples/sources/LICENSE.txt`) mixed with noise generated by upstream
  `demo/build_examples.py`; this derivative is likewise CC BY 4.0.
- `ref_noisy_4s.f32`, `ref_stream_16s.f32`: raw little-endian float32 output of
  `tools/parity/inworld_reference.py` (upstream `VoiceIsolator.isolate`, offline,
  PyTorch 2.8.0 CPU, float32, one thread) on those inputs. Regenerating them
  reproduces the files bit for bit. They are model outputs on the inputs above
  and carry the inputs' terms.
- `upstream_offline_3s/`: upstream's own golden fixture `tests/fixtures/offline_3s`
  (input, expected render of the training-side reference, `meta.json` with its
  max-abs tolerance of 1e-4), copied unchanged; CC BY 4.0 (LibriSpeech
  2277-149896-0032 with generated hiss), see upstream `tests/fixtures/README.md`.
  The pinned package itself matches it to 1.2e-7 and the 11 s golden to 1.8e-7
  (`inworld_reference.py --check-goldens`).

Regenerate:

    uv run tools/parity/inworld_reference.py --make-fixtures Tests/Fixtures/inworld
    uv run tools/parity/inworld_reference.py --weights <denoiser.safetensors> \
        --input Tests/Fixtures/inworld/noisy_4s.wav --output Tests/Fixtures/inworld/ref_noisy_4s.f32
    uv run tools/parity/inworld_reference.py --weights <denoiser.safetensors> \
        --input Tests/Fixtures/inworld/stream_16s.wav --output Tests/Fixtures/inworld/ref_stream_16s.f32
    uv run tools/parity/inworld_reference.py --weights <denoiser.safetensors> \
        --check-goldens <voice-isolator checkout>/tests/fixtures

Run the parity tests with
`MICPOLISH_INWORLD_WEIGHTS=<denoiser.safetensors> tools/test.sh --filter InworldMLXTests`;
add `MICPOLISH_INWORLD_UPSTREAM_FIXTURES=<voice-isolator checkout>/tests/fixtures`
to also check upstream's 11 s golden (two windows), which is not copied here.
